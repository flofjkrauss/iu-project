# iu-project
Coding Assignment for Programming with Python

# Installation
```
git clone --branch develop https://github.com/flofjkrauss/iu-project.git
cd iu-project
python -m venv .venv
.\.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```
